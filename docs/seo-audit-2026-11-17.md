# Auditoría SEO · Cale · 17/11/2026

Alcance: portada pública, rastreo e indexación. Primera entrega en dev.

## Hallazgos y cambios

1. **Prioridad alta: contenido inicial vacío.** El HTML de producción contenía root vacío y dependía de JavaScript para mostrar la portada. Se genera index.html desde el mismo componente React al compilar; no ejecuta efectos ni consulta cuentas o clientes. El panel conserva app.html sin contenido público insertado. No cambia el título solicitado por el titular.
2. **Prioridad alta: sitemap y robots ausentes (404).** El build genera ambos archivos. Producción enumera solamente la portada canónica; previews bloquean rastreo y generan sitemap vacío. No se bloquea el rastreo de rutas internas en producción para que Google pueda leer sus cabeceras noindex.
3. **Prioridad media: navegación como botones.** Se reemplazan por enlaces los accesos a precios, cómo funciona, alta/panel y textos legales. Se elimina el enlace anidado del logo.
4. **Prioridad media: compartir enlaces.** Se agregan tipo de sitio, idioma e imagen de marca a Open Graph y tarjeta social.

## Se conserva

- WebSite con nombre Cale y URL canónica de producción.
- Título: Recordatorios de turnos por WhatsApp.
- Noindex del panel, reservas de negocios y rutas internas; preview permanece noindex.
- Propiedad de cuentas y datos privados sin exposición adicional.
- WhatsApp con configuración asistida; no se agregan reseñas ni funciones inventadas.

## Siguientes prioridades

- Después de promover a producción, enviar sitemap.xml a Search Console.
- Medir Core Web Vitals con datos de campo y Lighthouse; esta revisión no certifica rendimiento.
- Evaluar páginas propias para peluquerías y centros de estética con contenido útil y casos comprobables.
- Revisar títulos, canonical y metadatos específicos de rutas secundarias antes de hacerlas indexables; actualmente reutilizan el shell y están excluidas del índice.
- Las URLs desconocidas de la SPA devuelven 200: revisar respuesta 404 real antes de ampliar páginas indexables.
- Revisar en Search Console indexación, impresiones y consultas después de acumular datos. Sin acceso a los reportes, no se infieren rankings ni tráfico.
