# Identidad de marca de Cale

Espacio central para guardar los recursos visuales y las decisiones de identidad de Cale.

## Estructura

- `logos/`: versiones del logo, isotipo y archivos exportados.
- `colors/`: paleta oficial y variables de color.
- `typography/`: tipografías y reglas de uso.
- `manual/`: manual de marca y guía de uso.
- `manual/guia-de-contenidos-y-aplicacion.md`: versión consolidada para redes y campañas.
- `assets/`: íconos, QR, ilustraciones y otros recursos.

## Recursos incorporados

- Logo horizontal: `logos/cale-lockup.svg`.
- Favicon: `logos/favicon.svg`.
- Ícono de aplicación: `logos/cale-app-icon-1024.png`.
- Perfil de WhatsApp: `logos/cale-whatsapp-profile-640.png`.
- Manual: `manual/manual-de-marca.md`.
- Paleta: `colors/paleta.md`.

Las piezas generadas anteriormente son conceptos visuales y no reemplazan estos recursos oficiales.
