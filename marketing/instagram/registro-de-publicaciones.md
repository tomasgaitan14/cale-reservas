## Cómo usar el registro

1. Consultar el historial antes de preparar cada entrega; comparar especialmente las últimas nueve publicaciones confirmadas, si existen.
2. Revisar tema, problema, beneficio, titular, imagen y composición para evitar duplicados. Se puede retomar una funcionalidad desde un enfoque nuevo.
3. Alternar situaciones del negocio, demostraciones y beneficios. Combinar fotografías, producto y tipografía manteniendo colores, logo y legibilidad. Cada publicación debe entenderse por sí sola.
4. Registrar las tres alternativas de cada entrega bajo un mismo ID y conservar sus archivos y descripciones. Indicar cuál eligió el usuario; las restantes no cuentan como publicadas.
5. Cuando el usuario avise que subió una pieza, actualizar el registro. Si no se conoce la variante o fecha, dejarlo indicado y aclarar únicamente el dato necesario. No inventar fechas ni enlaces.
6. Recomendar el siguiente contenido según lo publicado y los temas pendientes. Revisar el orden confirmado del feed cuando esté disponible; no asumir que se tiene acceso automático a la cuenta.
