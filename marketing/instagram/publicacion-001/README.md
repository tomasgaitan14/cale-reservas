# Publicación 001 · Reservas mientras atendés

Estado: requiere reformulación. El usuario considera las tres alternativas demasiado publicitarias para el feed y solicita un enfoque orgánico inspirado en agenda.mas. Ninguna elegida, aprobada, publicada ni programada. Se conservan los archivos para referencia.

- A: `opcion-a.png` · Tus clientes reservan. Vos atendés. Fotografía cálida de peluquería. Recomendada para abrir la comunicación.
- B: `opcion-b.png` · Un link. Sus próximos turnos. Visual de producto basado en la prueba aprobada; imagen generada, no una captura nueva del producto. Datos de ejemplo.
- C: `opcion-c.png` · Menos ida y vuelta. Más tiempo para atender. Mensajes y reserva ilustrativos.

Son alternativas para una sola publicación, no una secuencia de tres publicaciones consecutivas. Formato vertical aproximado 4:5. Imágenes generadas con la herramienta integrada imagegen, usando referencias oficiales y las pruebas aprobadas. Textos y composiciones revisados visualmente. Conservar originales; la generación puede reinterpretar detalles del logo y la interfaz.

Los pies de foto están en `descripcion-a.txt`, `descripcion-b.txt` y `descripcion-c.txt`. Los prompts completos y las referencias están en `prompts.md`.
